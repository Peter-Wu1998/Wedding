# 婚礼答谢网页

婚礼结束后的答谢单页。宾客打开后先看到加载进度，资源就绪后角色会自动接住飘落的花瓣；接到后姓名标签从接住位置平移到「衷心感谢」名单中（不展示礼金）。

## 功能特点

- **答谢文案**：顶部展示感谢语与新人姓名
- **宾客名单**：接到花瓣后，姓名以标签形式出现在「衷心感谢」区域
- **标签飞入**：姓名从接住位置平滑平移到名单对应格子，落地即显示
- **花瓣互动**
  - 一次只落一片，接到后再落下一片
  - 花瓣大小按礼金比例缩放（金额只用于大小，页面不显示）
- **加载页**：预加载全部角色动画帧后再开始互动
- **系统字体**：使用本机中文字体，不依赖在线字体 CDN
- **手机竖屏适配**：针对竖屏排版，便于转发分享

## 文件结构

```
Wedding/
├── index.html      # 主页面
├── style.css       # 样式
├── script.js       # 逻辑（名单、花瓣、角色、飞入动画）
├── frames/         # 角色动画帧 frame_0000.png ~ frame_0060.png（共 61 帧）
├── 名单            # 宾客姓名与礼金（对照参考，实际以 script.js 为准）
└── README.md
```

## 使用方法

### 1. 修改答谢文案与新人姓名

编辑 `index.html`：

```html
<p class="thanks-text">
    感谢您见证我们的幸福时刻<br>
    您的祝福，是我们最珍贵的礼物
</p>
<p class="thanks-names">伍良俊 &amp; 吴丹</p>
```

### 2. 修改宾客名单

编辑 `script.js` 中的 `guests` 数组。`amount` 只影响花瓣大小：

```javascript
const guests = [
    { name: '徐四斌', amount: 1000 },
    { name: '王正波', amount: 1000 },
    // ...
];
```

可对照同目录 `名单` 文件维护后，再同步到 `script.js`。

### 3. 本地预览

用浏览器直接打开 `index.html`，或在本目录启动本地静态服务后访问。

### 4. 部署上线

将整个 `Wedding` 文件夹（含 `frames/`）部署到 GitHub Pages、Vercel、Netlify 等静态托管即可。

## 自定义

| 项目 | 位置 |
|------|------|
| 背景色 | `style.css` → `body` 背景（当前为雾蓝绿，便于衬托粉色花瓣） |
| 花瓣下落速度 | `script.js` → `duration`（当前约 4–6 秒） |
| 花瓣大小范围 | `script.js` → `minPetalScale` / `maxPetalScale` |
| 角色帧数 | `script.js` → `TOTAL_FRAMES`（需与 `frames/` 一致） |

## 技术栈

- HTML5 / CSS3 / 原生 JavaScript（无框架、无构建）

## 注意事项

1. 部署时必须上传 `frames/`，否则角色动画无法显示
2. 建议在手机竖屏下确认排版与接花瓣体验
3. 页面上的姓名不会显示礼金金额，请勿把金额写进文案
